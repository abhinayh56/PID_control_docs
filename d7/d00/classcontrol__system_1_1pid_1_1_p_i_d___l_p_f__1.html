Detailed Description

template<typename T>
class control_system::pid::PID_LPF_1< T >

PID controller with a first-order low-pass filtered derivative.

The PID_LPF_1 class implements a discrete-time PID controller in which the derivative contribution is filtered using a first-order low-pass filter.

The controller is configured using the sampling time, proportional gain, integral gain, derivative gain, and derivative filter cutoff frequency.

Previous controller outputs and control errors are retained internally to implement the discrete-time controller.
