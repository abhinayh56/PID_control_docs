Detailed Description

template<typename T>
class control_system::derivative::D_LPF_1< T >

Derivative controller with a first-order low-pass filter.

The D_LPF_1 class implements a discrete-time derivative controller with a first-order low-pass filter applied to the derivative action.

The controller uses the sampling time, derivative gain, and filter cutoff frequency to calculate the derivative contribution.

The previous control error and controller output are maintained as internal state, and the controller output is limited by the configured maximum output.
