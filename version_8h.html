Detailed Description

Version information for the Control System library.

This header defines the version information for the Control System library.

The library version follows the MAJOR.MINOR.PATCH format. The version is available both as preprocessor macros and as C++ constants in the CONTROL_SYSTEM namespace.

The numeric version is encoded as:

MAJOR * 10000 + MINOR * 100 + PATCH

For example, version 1.2.3 is represented numerically as 10203.
