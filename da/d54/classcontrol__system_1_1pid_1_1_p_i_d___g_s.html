Detailed Description

template<typename T>
class control_system::pid::PID_GS< T >

PID controller with gain scheduling.

The PID_GS class implements a discrete-time PID controller whose proportional, integral, and derivative gains can be adjusted according to a configurable operating condition.

Gain scheduling is implemented using lookup tables containing operating-condition values and corresponding proportional, integral, and derivative gains. Gain values between lookup-table points can be obtained through interpolation.

The derivative contribution can optionally be filtered using a first-order low-pass filter. A feed-forward contribution can also be added to the controller output.

The integral contribution and final controller output are subject to configurable limits.
